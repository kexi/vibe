vibe needs a shell wrapper function to change directories after creating or cleaning up worktrees. Add the appropriate configuration to your shell.

## Shell Configuration

<Tabs>
  <TabItem label="Zsh">
    Add **one** of the following to `~/.zshrc`. Do not add both — the wrapper would be defined twice.

    Recommended — wrapper function with tab completion (subcommands, flags, and branch names for `vibe start` / `vibe jump`):

    ```bash
    autoload -Uz compinit && compinit
    eval "$(vibe shell-setup --shell zsh --with-completion)"
    ```

    The two lines define the `vibe` wrapper and register the zsh completion together. The `compinit` line is required for zsh's completion system — if you already invoke `compinit` elsewhere in your `~/.zshrc`, place the `eval` line *after* that call. If `compinit` has not run, the completion registration is silently skipped and the `vibe` wrapper is still defined.

    Wrapper only (no tab completion):

    ```bash
    vibe() { eval "$(command vibe "$@")" }
    ```

  </TabItem>
  <TabItem label="Bash">
    Add to `~/.bashrc`:

    ```bash
    vibe() { eval "$(command vibe "$@")"; }
    ```

  </TabItem>
  <TabItem label="Fish">
    Add **one** of the following to `~/.config/fish/config.fish`. Do not add both — the wrapper would be defined twice.

    Recommended — wrapper function with tab completion (subcommands, flags, and branch names for `vibe start` / `vibe jump`):

    ```fish
    vibe shell-setup --shell fish --with-completion | source
    ```

    This single line both defines the `vibe` wrapper and registers fish completions.

    Wrapper only (no tab completion):

    ```fish
    function vibe
        eval (command vibe $argv)
    end
    ```

  </TabItem>
  <TabItem label="Nushell">
    Add to `~/.config/nushell/config.nu`:

    ```nu
    def --env --wrapped vibe [...args] {
        let out = (^vibe --eval-dialect nu ...$args)
        for line in ($out | lines) {
            if ($line | str starts-with "__VIBE_CD__") {
                cd ($line | str replace "__VIBE_CD__" "")
            } else {
                print $line
            }
        }
    }
    ```

    :::note
    Requires vibe 2.2.0 or later and nushell 0.83 or later. If you previously pasted the
    older `nu -c` snippet, replace it — that version never actually changed your directory,
    because `nu -c` runs `cd` in a child process, and it rejected any command carrying a
    flag. Both `--wrapped` and `for` are required: `--wrapped` lets flags through to
    `...args`, and nushell discards environment changes made inside an `each` closure.
    :::

  </TabItem>
  <TabItem label="PowerShell">
    Add to your `$PROFILE`:

    ```powershell
    function vibe { $out = & vibe.exe --eval-dialect powershell @args; if ($out) { Invoke-Expression ($out -join "`n") } }
    ```

    :::note
    Requires vibe 2.2.0 or later. If you previously pasted the older
    `Invoke-Expression (& vibe.exe $args)` snippet, replace it — that version mishandled
    paths containing a single quote and threw an error whenever vibe produced no output.
    :::

  </TabItem>
</Tabs>

## Using mise (automatic setup)

If you installed vibe with [mise](/installation/), you can automate shell setup
using mise's [hooks](https://mise.jdx.dev/hooks.html) feature.

Add the following to your project's `.mise.toml`:

```toml
[hooks]
enter = 'eval "$(vibe shell-setup)"'
```

:::note
This requires [`mise activate`](https://mise.jdx.dev/getting-started.html#activate-mise) in your shell.
The `enter` hook runs automatically when you enter the project directory, detecting your shell
and defining the appropriate wrapper function.
:::

## Why is this needed?

When vibe creates a worktree, it needs to change your current working directory to the new worktree. However, a subprocess cannot change the parent process's directory directly.

The shell wrapper function captures vibe's output (which contains shell commands like `cd /path/to/worktree`) and executes it in the current shell context.

## Verify Installation

After adding the shell configuration, reload your shell and verify:

```bash
# Reload your shell or open a new terminal
source ~/.zshrc  # or ~/.bashrc, etc.

# Check vibe is working
vibe --help
```
